### [Online File Converter](https://github.com/Jaroslaw-Baumgart/OnlineConverter-app)

A fullstack file conversion application built with React, TypeScript, Node.js, and Express.

- Supports PDF, image, text, CSV, and Office document conversions.

- Includes frontend and backend tests and English/Polish language support.

**Tech:** React, TypeScript, Node.js, Express, Vitest, Supertest

### [TypeScript Shell](https://github.com/Jaroslaw-Baumgart/codecrafters-shell-typescript)

A command-line shell implemented in TypeScript, originally developed as part of the CodeCrafters challenge.

- Implements command parsing using a lexer, parser, and abstract syntax tree (AST).
- Supports built-in commands, external processes, pipelines, and output redirection.
- Handles environment variables, command history, and background jobs.
- Uses a modular architecture separating parsing, execution, and terminal I/O.

**Tech:** TypeScript, Node.js, Bun
